Después de los arreglos: la historia de prueba

Agenda de visitas en Real State. El cliente ve los horarios disponibles y reserva una visita al inmueble, y tú las ves en el tablero. No depende de Kapso, WhatsApp ni Meta. Toca Python y el tablero web, así que prueba justo el grupo 4. Se mide todo: tus minutos, los tiempos de cada etapa, RAM, CPU, costo, memoria y si decidiste sin abrir el código. Después sigue el estimador de precio, cuando decidamos de dónde salen los datos de comparables.
